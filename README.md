FIDE-rules-compliant chess engine

## Features

- Elo 2050
- Protocol UCI
- Single C file
- Board: bitboard
- En passant
- Underpromotions (knight, bishop, rook)
- Threefold repetition
- 50-move rule
- Stalemate and checkmate reported correctly to the GUI
